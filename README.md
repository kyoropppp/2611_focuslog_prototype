# FocusLog — 研究・哲学・LLM の時間割と実績を記録するプロトタイプ

モデル時間割と実績を**同じ時間軸に上下2段で表示**する、PC・スマホ対応の個人用Webアプリです。

画面イメージは `docs/preview_desktop.png`（PC）と `docs/preview_mobile.png`（スマートフォン）で確認できます。

## 動作環境

- **Python 3.10以上**（追加ライブラリ不要）
- Windows 10/11、macOS、Linuxのモダンブラウザ
- スマホ側：Chrome / Safariなど（PCと同じWi-Fiからアクセス）

## Windows：起動方法

1. ZIPを展開し、`focuslog_prototype` フォルダーを開く。
2. `start_windows.bat` をダブルクリックする（またはPowerShellで `py -3 server.py --host 0.0.0.0`）。
3. PCのブラウザで **http://127.0.0.1:8765** にアクセスする。
4. スマホからは、同じWi-Fiに接続して `http://PCのローカルIP:8765` にアクセスする。

ローカルIPの確認方法：Windows PowerShellで `ipconfig` を実行し、Wi-Fiアダプターの **IPv4 アドレス** を確認します。例えば `192.168.1.25` であれば、スマホのURLは `http://192.168.1.25:8765` です。Windowsファイアウォールで、**プライベートネットワーク**へのPythonの着信通信を許可する必要がある場合があります。

終了：起動した黒いウィンドウで **Ctrl+C** を押します。PCがスリープしたりサーバーを終了すると、スマホからアクセスできません。

## macOS / Linux：起動方法

```bash
python3 server.py --host 0.0.0.0
```

PCだけで使用する場合は `python3 server.py` でも起動できます。

## 実装済みの機能

- 曜日ごとのモデル時間割。現在合意した月〜日の予定を初期登録済み
- **2026/11/17**（火）は輪読がない例外日として、10:00〜12:00を研究に変更済み
- **「前日」「翌日」矢印、カレンダーアイコン、今日ボタン**による日付移動
- **横スクロールできる7:00〜23:00の共通時間軸**（開始・終了時刻は設定変更可）
- モデル予定の編集・追加・削除（**この日だけ** / **毎週この曜日**）
- モデル予定からの実績入力と、独立した「実績を追加」の両方
- 実績の手入力：日付、開始、終了、カテゴリ、テーマ、作業内容、任意メモ
- テーマの入力補助・新規登録・名前変更・アーカイブ
- 重複する実績の注意表示（重複は許容し、そのまま合算）
- 日ごとの実績時間と研究モデル時間、週ごとの集計グラフ
- CSV（実績）、JSON（全データ）のエクスポート
- SQLiteによる永続保存。PCと同じサーバーに接続するスマホの間で同期

## 初期モデル時間割について

- 月・水：7:00〜12:00の研究（9:30〜10:00は休憩）、13:00〜18:00はオンラインバイト。18:00以降はマージン。月曜は21:00〜23:00に講師MTG。
- 火：自宅7:00〜8:00の研究枠は**登録していません**。8:00〜10:00は通学（研究可能最大90分）、10:00〜12:00輪読、12:00〜14:00昼食会。
- 木：15:00〜23:00はバイト。
- 金：17:00〜20:00はゼミ。**ゼミ準備の枠はありません**。
- 土日：午前から昼過ぎまで研究、午後は哲学・LLMを任意で実施。
- 通学の研究90分は「移動」枠の中で使える見込み時間として研究計画に計上します。**自動で実績に計上されるわけではありません**。

## データの保存先

最初の起動時に `data/focuslog.db` が自動作成されます。これは実データなので、PCで適宜バックアップしてください。JSONのエクスポートもできます。なお、**このプロトタイプにはJSONインポート機能はありません**。起動するPCが異なる場合、DBファイルをコピーしない限り別のデータになります。

## セキュリティと制約

**認証機能はありません。インターネットに直接公開しないでください。** `--host 0.0.0.0` は同じネットワークの端末からアクセスできる状態になります。信頼できる家庭内LANなどでの使用を想定しています。家庭外からの接続や外出先での同期には、認証付きの安全なホスティング構成が別途必要です。

- スマホとPCが同時に同じ画面を開いた場合、リアルタイムの自動更新ではなく、日付の切り替え・画面の再読み込み時に最新データを読み込みます。
- 実績が時間的に重なっていても登録できます。集計は各実績時間を合算するため、重複分は二重計上されます。
- 作業実績の終了時刻が日付をまたぐ記録は未対応です。
- モデル予定を「この日だけ変更」すると、その日全体のモデルが日付固有のスナップショットになります。その後に毎週モデルを変更しても、その日には自動反映しません。「この日の例外設定を解除」で基本モデルへ戻せます。
- 1件のモデル予定が表示範囲外の場合、その時間帯はタイムラインに表示されません（実績一覧には記録されます）。
- 自動タイマーは仕様外で、実績はすべて手入力です。

## 技術構成

- Python標準ライブラリ `http.server` + JSON API
- SQLite3（Python標準ライブラリ）
- HTML / CSS / バニラJavaScript（ビルド不要、外部CDNなし）

フォルダー構成：

```
focuslog_prototype/
  server.py               # APIサーバー・SQLiteデータ管理
  start_windows.bat       # Windows用起動スクリプト
  static/
    index.html            # 画面
    app.js                # UIとAPI通信
    styles.css            # PC/スマホ兼用スタイル
    favicon.svg
  docs/
    preview_desktop.png   # PC画面のプレビュー
    preview_mobile.png    # スマホ画面のプレビュー
  tests/
    test_server.py        # バックエンドのテスト
  data/
    .gitkeep              # ここにDBを自動生成
```

## 今後決めること

1. **外出先からもアクセスしたいか**（クラウド公開・認証・HTTPSが必要になる）。
2. 同じ時間に重なって登録した作業を、**許可／禁止／警告のみ**のどれにするか（現状は警告のみ）。
3. **研究目標の運用**（移動中の見込み時間を計画に含めるか、月・水の研究4.5hを固定目標とするか等）。
4. 入力作業をさらに簡単にするための**よく使う作業内容のテンプレート**や、週次レポートの必要性。
